# Native ordinary QSA Q/K/V projections, T1 trial

`--native-qsa-qkv-t1` is an opt-in experiment layered on the existing native QSA WO path. It requires the ordinary serial HC, native norm/RoPE and attention, resident dense weights, eager execution, and the existing strict accelerator admission. The default remains off. Chunked execution, quantized KV, indexer projections and scheduling changes are outside this experiment.

The actual completed HC mixed tensor supplies 2,560 floats to one reciprocal-observation Q8_1 producer. Its 2,880 packed bytes are passed directly to all three Q8_0 consumers. The Q output has 12,288 floats, including each head's interleaved 256 query and 256 gate values. K and V each have 512 floats. The native-order consumer uses four logical warps, two signed packed dots per fragment, a separately rounded scale product, FMA accumulation, sequential warp-partial additions and XOR reduction. Existing norm/RoPE and attention consume the resulting candidate, and the existing FFN transaction still controls state commit.

Before model execution, `tools/native_qsa_qkv_role_preflight.py` scans the six ordered GGUF shards. It checks all 36 Q/K/V role types, shapes, byte spans, hashes and half-scale classes. Nonfinite weight scales are refused; finite half subnormals retain their original bits. The model repeats the role and resident-byte checks before requests. Input and packed Q8_1 domain checks remain conservative and stop on unsupported classes.

The deterministic component fixture is generated locally by `native_qsa_qkv_input_test --synthetic DIR`. Native and Vulkan producer startup contracts name all four output images. The test fixture contains separate query/gate and K/V literal rows, plus a cancellation case distinguishing the native four-warp order from a different lane partition. `tools/native_qsa_qkv_compare.py` validates the frozen fixture and compiled control, requires the independent packed and output literals, and compares all 2,880 packed bytes and all 53,248 projection bytes exactly. Both producers must also pass canary, repeat, stale-input and invalid-call checks.

The reciprocal and FMA shaders remain observation candidates. Local host providers and shader structure checks do not establish CUDA/Vulkan bit parity. A bounded native-first component comparison, compiled instruction/module inspection, actual role preflight, fresh admission and existing cleanup guards are required before a model attempt. Results apply to the tested inputs and stack, not general reciprocal/FTZ equivalence or full-model parity.
