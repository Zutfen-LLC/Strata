# Native PLE gate observation

This standalone T1 Vulkan component targets `native_ple_postops.cu::gate_kernel`, selected by the native Strata preset. It consumes the four already-normalized key and query rows. It does not implement the three RMS normalizations, the value broadcast, convolution, residual write or history advance, and it is not used by the portable model. The ordinary portable PLE path and its transaction handling are unchanged.

The candidate preserves the native 512-lane partition, separate F32 products, eight ordered per-lane additions, XOR reductions, FMA scale, sign and magnitude order. Its output includes four gates and four diagnostic values per row: reduction, scaled score, exponent and denominator. The implementation reuses the existing Vulkan observation owner; on the current stack that owner also requires the existing Q8 integer-dot and strict-FMA capabilities. It accepts finite normal or zero inputs and refuses nonfinite or subnormal intermediate results. This is a bounded diagnostic domain: native CUDA may handle additional values, including a valid extreme negative sigmoid tail.

CUDA and Vulkan do not guarantee identical `exp`, `sqrt` or division results. This candidate does not claim cross-backend equality or define a new tolerance. The local literal controls test reduction order, not native hardware parity. Before model integration, run the existing native `native_ple_postops` launcher, capture its actual normalized key and query outputs, and compare the Vulkan candidate on those same inputs. Inspect the compiled native gate instructions and the effective Vulkan module, record backend primitive differences and apply the established per-backend contracts. No history state should be advanced by this component.

With a strict-FMA native-stage build, run `ctest --output-on-failure -R '^native_ple_gate_'`. The tests cover source-order literal reductions, actual backend dispatch contracts with a mock device, the standalone component's startup contract without GPU initialization, and optimized SPIR-V arithmetic and geometry. They do not launch a GPU or model.
